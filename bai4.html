Bài 4: Lists - Danh Sách Trong HTML

30/12/2025 | Nguyễn Văn A

3 loại danh sách chính

1. Unordered List (<ul>) - Dấu chấm

<ul>
    <li>Cà phê sữa đá</li>
    <li>Trà chanh</li>
    <li>Sinh tố bơ</li>
</ul>

2. Ordered List (<ol>) - Đánh số

<ol>
    <li>Thức dậy lúc 6h</li>
    <li>Tập thể dục</li>
    <li>Ăn sáng</li>
    <li>Bắt đầu học HTML</li>
</ol>

3. Description List (<dl>) - Từ điển

<dl>
    <dt>HTML</dt>
    <dd>Ngôn ngữ đánh dấu cấu trúc trang web</dd>
    <dt>CSS</dt>
    <dd>Ngôn ngữ định dạng giao diện đẹp mắt</dd>
    <dt>JavaScript</dt>
    <dd>Ngôn ngữ làm web tương tác</dd>
</dl>

Danh sách là cách trình bày thông tin rõ ràng, dễ đọc nhất trên web!
